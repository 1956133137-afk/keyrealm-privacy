1. 适用范围

本政策说明“迷踪逃脱”对用户及设备数据的处理方式。最终政策应与实际发布版本和 Google Play 的“数据安全”声明保持一致。

2. 本地游戏数据

游戏在设备上保存关卡进度、游戏币、体力、签到状态、道具，以及音乐、音效和振动设置，用于恢复游戏状态和保留您的偏好。已检查的游戏脚本通过本地存储保存这些信息，未发现将其上传至开发者服务器的网络请求。

游戏内排行榜为本地虚拟展示，不代表真实玩家的实时竞争排名。已检查的排行榜入口仅打开本地界面，未发现向远程排行榜提交玩家成绩的调用。

3. 权限与第三方服务

当前 Android 工程声明了互联网、网络状态和 Wi-Fi 状态权限。具有网络权限本身不代表应用一定收集或上传数据；正式政策应说明实际启用服务的用途与数据处理方式。

待确认：当前 Google Play 构建配置启用了 Google Play Games。需要核验最终发布包是否初始化或登录该服务，以及实际访问、传输的数据，再补全相应说明。不能据此草稿声称整个应用完全离线或完全不收集数据。

第三方服务的相关说明可参见 Google 隐私政策。本链接不能代替对本应用具体数据处理方式的披露。

4. 保存、删除与用户选择

设备上的游戏存档和设置通常保留至您清除应用数据或卸载应用。您可以在 Android 设置中打开“应用 → 迷踪逃脱 → 存储”，清除本地数据。此操作会重置本地进度和设置，且不会自动删除由第三方服务另行保存的信息。

待确认：若最终版本启用账号、云存档或其他服务器数据，需要补充相应的保存期限、删除方式和请求处理流程。

5. 数据安全

本地数据受 Android 应用沙箱保护。发布版本如启用网络数据传输，应核实并披露相应安全措施。任何存储或传输方式都不能保证绝对安全。

6. 儿童与适用人群

待确认：根据最终游戏内容、目标受众及年龄分级补全本节，不预先声明面向儿童或不面向儿童。

7. 政策更新

如果游戏功能或数据处理方式发生变化，我们会相应更新本政策及更新日期。

8. 联系方式

本应用由 GitHub 账号 1956133137-afk 维护。关于隐私、本地数据删除或本政策的问题，可通过 迷踪逃脱 GitHub Issues 联系开发者，并在标题注明“隐私 / Privacy”。提交公开问题需要 GitHub 账号；请勿在公开问题中提交密码、身份证件或其他敏感个人信息。
